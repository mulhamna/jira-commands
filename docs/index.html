Why jirac

More than a thin REST wrapper.

A daily-driver toolkit for the people who live in a terminal — and the agents that work alongside them.

CLI · TUI · MCP

One tool, three surfaces: scriptable CLI, a keyboard-driven TUI, and an jirac-mcp server for AI agents.

JQL, the easy way

Interactive query builder by project, status, and assignee — plus saved JQL flows you can re-run instantly.

Reports in seconds

Daily standups, sprint summaries, worklog backfills across date ranges, and mention notifications — straight to the terminal.

Native bulk + moves

Change issue type, move across projects with native semantics, and bulk-comment, -transition, -update, or -create.

Custom fields, auto-mapped

Runtime field introspection per project — no manual YAML mapping to maintain. Built on the latest Jira API v3.

Cross-platform & fast

A single Rust binary for macOS, Linux, and Windows. Quick to install, quicker to run.

FAQ

Good to know.

Where do I get a Jira API token?

From your Atlassian account security settings, under “API tokens”. Run jirac auth login and paste your Jira URL, email, and token — it’s stored in ~/.config/jira/config.toml with 600 permissions.

Is this replacing the Jira web UI?

No. jirac complements the web UI for terminal-first and automation workflows — browsing, JQL, worklogs, transitions, versions, and MCP/agent access.

Does it support custom fields?

Yes. Custom fields are discovered dynamically per project at runtime, so there’s no manual field mapping to maintain.

Can I use jirac as my main Jira CLI?

Absolutely — it’s built to be a daily driver covering issue browsing, JQL search, worklogs, transitions, fix versions, project versions, bulk actions, and MCP workflows.

How do I copy text out of the TUI?

Hold Shift (iTerm2 / most Linux terminals) or Option (Terminal.app) while selecting. Under tmux, set set -g mouse on so events reach the TUI.
